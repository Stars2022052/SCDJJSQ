它是怎么算的

  • 1先做确定性推导。用基础规则与子集规则（1-2 这类交叉约束）把所有能从逻辑上确定的格子推出来。
  • 2再枚举所有合法布局。对剩下的未知格按连通分量做完全枚举，得到每一格在全部合法解中出现钻石的次数。
  • 3按全局钻石总数加权。棋盘上钻石总数是固定的，剩余钻石怎么分配会反过来改变概率，这一步让结果符合真实分布。
  • 4最后挑出最值得点的一格。先比概率，并列时比周围已知数字多少，再避免边角格。
关于准确度：概率结果是「在全部满足约束的布局中均匀计数」，不是平均、不是密度估算。 只有在极少数边界过大、枚举规模爆炸的情况下才会自动切到最大熵近似，并在界面上明确标注「近似」。

关于部署：把这三个文件放进仓库根目录，开启 GitHub Pages（Branch: main / 目录 / (root)）即可得到一个公开网址。 计算器本身是单个 HTML、零外部依赖，双击也能离线打开。
